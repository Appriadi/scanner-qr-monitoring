Scanner QR — Monitoring Kawasan

Halaman ini khusus membaca QR melalui kamera. Setelah token terbaca, salin token lalu tempel ke kolom token pada aplikasi Monitoring Kawasan.

Siap. Tekan “Buka Kamera” dan izinkan akses kamera jika diminta.

Privasi: pembacaan QR dilakukan di browser. Token tidak dikirim oleh halaman ini ke server mana pun. Setelah disalin, buka aplikasi Monitoring Kawasan di tab lain dan tempel token ke kolom “Masukkan token QR manual”.
